It's the Claude Code you already use.

Each session is the real claude command with your own login, so your settings, skills and slash commands all still work. {{name}} gives each one a tile, listens to Claude Code's hooks to know what it's doing, and points you at the one that's waiting.

Calm

The tile you're typing in never moves. Others grow and shrink around it. Nothing pops up and disappears on a timer.

No extra tokens

The hooks reply with nothing and the counters are read from local files. The few things that do cost tokens are ones you start yourself.

Mac and Windows

One app for both, with the right shortcuts on each. Works on any folder, git or not.

Built around one question: what needs me?

Every session at a glance

Each tile shows a status you can read without colour: ○ idle, ● working, ◆ needs you, ✓ done. The top bar counts them, and a notification tells you when a session waits on you or finishes something long.

Drag tiles to swap them, drag an edge to resize, or pin one to keep it big.

The overview

Press ⇧⌘A (Ctrl+Shift+A on Windows) for one list of every session, sorted by what needs you first. The side pane shows the end of the conversation, and you can answer a permission prompt with a number key without leaving the list.

Snooze a session that keeps asking. Done stays green until you've looked at it.

Modes

Tell a session how to work with one click: Notes, Plan, Build, Review, Careful, Until done and more, or write your own. Add-ons like Verify at end or Quiet stack on top.

Some modes have real limits. In Plan and Review, Claude can't edit files. In Careful, it can't push or deploy. A hook blocks the tool call, so it doesn't rely on Claude reading the instructions.

Command palette

⌘K on Mac, Ctrl+Shift+K on Windows. Jump to a session, switch workspace, set a mode, start a recent folder. Rows show their shortcuts, so you pick them up as you go.

Usage you can see

Your plan's 5-hour and weekly limits sit in the top bar, with when they reset. Open them for what each session has used, and the last 14 days by day and by project.

All of it comes from files Claude Code already writes. No API calls.

Workspaces

Group sessions by project and switch between them. Put one away and reopen it later with its sessions and modes. With one workspace you never see them.

The overseer

A side panel with its own small Claude that can see every session. Ask "anything waiting on me?" It only types into a session when you tell it to.

Time budgets

Give a session 30 minutes. Claude gets a short note to plan for it, a nudge at 80% and a "finish now" at the end. Nothing is ever killed.

Fresh start

When the context fills up, Claude writes a handover, the context is cleared, and the session carries on from the handover.

Clean view

Flip any tile to a tidy chat: your messages, Claude's replies, and tool calls folded into one line. It types into the same real session.

Agents you can see

Subagents show up under their tile with their job, how long they've run and the tokens they've used.

History and branches

Search past conversations per folder and resume one in a tile. Fork a session into a second tile, or start one on its own git branch.

Light and dark

Follows your system, with a high contrast option and a compact density.

Free, open source and private.

No account, no telemetry

There's no server to sign in to and nothing is tracked. The only request the app makes by itself is checking GitHub for updates.

Tokens only when you ask

Watching sessions costs nothing. The overseer, Fresh start, modes and time budgets do use tokens, and you start each of them yourself.

Download

The builds aren't signed by Apple or Microsoft yet, so the first launch needs one extra step. It's below each download.

Mac

Apple silicon Intel
  1. Open the .dmg and drag {{name}} into Applications.
  2. In Terminal, run this once: 
    xattr -cr "/Applications/{{name}}.app"
    Or right-click the app, choose Open, then Open again.
  3. Open it and allow notifications.

Windows

Windows x64 Windows on ARM
  1. Run the installer.
  2. If SmartScreen says it doesn't recognise the app, click More info, then Run anyway.
  3. Make sure claude works in PowerShell.

You need Claude Code installed and logged in. Check that claude runs in a normal terminal first. Full install notes, or all releases.
