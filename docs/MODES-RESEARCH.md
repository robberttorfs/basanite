# Modes research (4 Nov 2026)

Mined from ~3,200 typed prompts (Jul–Nov 2026), ~1,160 transcript user messages, memory files and handovers.

| Mode | Evidence | Exit phrase |
|---|---|---|
| Notes (collect, don't act) | ~110 prompts | start / go |
| Overnight / autonomous build | ~55 | (none, runs to the end) |
| Plan / discuss only | ~160 | go ahead |
| Phased build with checkpoints | ~75 | next phase |
| Review only (read-only audit) | ~60 | now fix it |
| Polish sweep (expert review rounds) | ~45 | (none) |
| Careful (production-adjacent) | ~68 + hard rules | (none) |
| Delegate (crew build) | ~43 | (none) |
| Handover / save state | ~71 | (none) |

Standing rules the owner repeats everywhere: no clutter, minimal text; don't look AI-made (no emojis, no "·" separators, no em dashes, no "…" cut-offs, no explainer lines); reports as local HTML with before/after screenshots, never Artifacts; never deploy or touch main without approval; minimal paid API tests and tokens; recommend one option and act; final questions once, up front; plain short English.

Common switch phrases: "go" (22), "start" (14), "get started", "go ahead", "do it"; into discussion: "discuss", "lets discuss now".
