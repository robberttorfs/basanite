Docs

{{name}} runs your Claude Code sessions side by side as tiles. This page covers installing it and everything it does.

Install

You need Claude Code installed and logged in. Check that claude --version works in a normal terminal first.

Mac

  1. Download the Apple silicon build for M1 and newer, or the Intel one for older Macs.
  2. Open the .dmg and drag {{name}} into Applications.
  3. The app isn't notarised by Apple yet, so the first launch needs one extra step. In Terminal, run: 
    xattr -cr "/Applications/{{name}}.app"
    Then open it normally. Or right-click the app, choose Open, then Open again.
  4. Allow notifications when asked.

Windows

  1. Download the x64 installer, or the ARM one for Snapdragon laptops.
  2. Run it. If SmartScreen says it doesn't recognise the app, click More info, then Run anyway.
  3. Pick a folder or keep the default, and finish the installer.

On Windows, Claude Code must run as claude from PowerShell. {{name}} starts it through your login shell, so it sees the same PATH as your terminal.

Updates: on Windows the app downloads new versions quietly and offers to restart. On Mac it tells you a new version is out and opens the download page.

First session

Drop a project folder anywhere on the window, press ⌘N (Ctrl+Shift+N on Windows), or click a recent folder. Continue on a recent folder picks up its last conversation instead of starting fresh.

Click a tile and type, exactly like a terminal. Drag files onto a tile to paste their paths. Shift+Enter adds a new line. You can also open a plain terminal from the same New window.

Quitting stops the sessions, and they resume where they were the next time you open the app.

Tiles

Each tile shows a status shape and word: ○ idle, ● working, ◆ needs you, ✓ done, ✕ error. A session that needs you grows and glows amber, and quiet ones shrink. The tile you're working in never moves while others change.

  • Arrange: drag a tile by its header onto another to swap them. Drag the gap between tiles to resize; that size holds (a lock shows) until you click the lock or double-click the edge. Pin a session to keep it big on the left.
  • Name and colour: double-click a name, or press ⇧⌘R.
  • At a glance: a quiet line with the latest step ("Editing routes.ts"), the git branch with a dot for uncommitted changes, and a read-only peek at the changed files. If two sessions edit the same file, both tiles say so.
  • Agents: subagents show as chips under the header with their job, run time and tokens.
  • Clean view: the speech-bubble icon (⇧⌘L) flips a tile to a tidy chat. Tool calls fold into one line you can open. What you type goes into the same session, and permission menus switch back to the terminal by themselves.
  • History and branches: the tile menu lists past conversations in that folder, so you can resume one. Branch forks the conversation into a second tile (it re-reads the context once, so it costs tokens). Own branch on New starts a session in its own git worktree.

Workspaces

A workspace is a named set of sessions with their layout, modes and pins, such as "School" or "Website". With only one, you never see them. Make a second from the palette (New workspace) and pills appear in the top bar.

  • Switch with the pills, ⌃⌘← / ⌃⌘→ (Ctrl+Alt+← / Ctrl+Alt+→), or ⌥⌘1 to ⌥⌘9 (Ctrl+Shift+1 to 9). Sessions in other workspaces keep running.
  • A workspace with a session that needs you gets an amber dot on its pill.
  • Put away stops its sessions; reopen it later and they come back with their modes.
  • Drag a tile onto a pill to move it there. Drop a folder on a pill to start a session in it.
  • Each workspace can have its own colour, notification level and default mode.

Overview

Press ⇧⌘A (Ctrl+Shift+A) or click the counts in the top bar. Every session, in every workspace, is listed by what needs you first, with how long it's been in that state.

  • The right pane shows the end of the conversation. If Claude is asking for permission, press the option's number to answer from here.
  • ↑ ↓ to move, ↩ to open the session, H to snooze, ⌫ to mark as seen, Esc to close.
  • Snooze stops a tile glowing for 30 minutes, or until its status changes.
  • Done stays green until you've looked at that session, then quietly becomes idle.

Palette and shortcuts

⌘K on Mac, Ctrl+Shift+K on Windows. Type to find sessions, workspaces, modes, recent folders and every action. With nothing typed, it shows sessions that need you and your recent commands. If nothing matches, the last row asks the overseer.

Modes and add-ons

A mode is a saved set of instructions for how a session should work. Click the mode chip on a tile (⇧⌘M) and pick one. The chip is outlined until your next message carries the mode to Claude, then filled.

  • Built in: Notes, Plan, Build, Overnight, Review, Careful and Until done, with Test first, Debug, Spec first, Phased, Refine and Crew under More.
  • Add-ons stack on top of a mode: Verify at end, Tidy commits and Quiet.
  • Real limits: Plan and Review block file edits and commands that write. Careful blocks pushes, deploys and destructive commands. A hook stops the tool call itself, so it doesn't depend on Claude following the words.
  • Ending a mode: modes like Notes end when your whole message is one of their end words, such as "start" or "go". A word inside a sentence never counts, and the tile offers Undo.
  • Cost: each mode shows 0 to 3 dots for how many tokens it tends to add. The instructions go to Claude once, with your next message, and again after a compaction.
  • Your own: edit, hide or add modes under Edit modes. Make a mode from this session asks the overseer to draft one from how you've been instructing a session. Modes save as .hangar-mode.json files you can share.
  • You can set a default mode per project and per workspace. The tile menu also has one-click Review and Simplify, which run Claude Code's own /code-review and /simplify.

Overseer

Click Overseer (⇧⌘O) for a side panel with its own small Claude that can see all your sessions. Ask in plain words: "anything waiting on me?" or "tell the website session to use teal".

It only types into a session when you ask it to, and it checks the screen first so a permission menu gets a number, not a sentence. New chat starts it fresh.

It runs Sonnet with one tool and no MCP servers, plugins or skills, so a question starts from about 6k tokens of context. It reads a one-line summary of each session first and only opens a session's messages when your question needs them. When you aren't asking it anything, it uses nothing.

Time budgets

Click the clock on a tile (⌘T), pick 10 to 90 minutes or type your own. If Claude is already working the budget starts now, otherwise with your next prompt.

Claude gets a short note at the start so it plans to fit, a "start wrapping up" note at 80% and a "finish now" note at the end. The clock changes colour at 80% and when time is up. Nothing is ever killed; Claude is only told to wrap up.

Fresh start

When a session's context gets full, the tile offers Fresh start (from 60% context). It's also in the tile menu and the palette. Claude writes a handover, the context is cleared, and the session carries on from the handover. If Claude is busy, it waits for the turn to end.

Writing the handover costs a turn's worth of tokens. Everything after it starts from a much smaller context.

Usage

The top bar shows your plan's 5-hour and weekly usage. Click it (⇧⌘Y) for when each limit resets, what every open session has used, and a chart of tokens per day and per project.

Each tile also shows its context with a bar, and quietly notes when its prompt cache has gone cold, since the next message will cost more.

The 5-hour and weekly numbers only exist for claude.ai Pro, Max and Ultra plans, and appear after the first reply.

Privacy and tokens

  • No account, no telemetry, no server. The only request the app makes by itself is the update check to GitHub Releases.
  • Sessions are ordinary claude processes using your own login. The app talks to them over 127.0.0.1 with a random key per launch.
  • Your global Claude Code settings aren't changed. Each session gets its hooks through its own settings file.
  • The hooks reply with nothing, and counters are read from Claude Code's own local files, so watching sessions costs no tokens.
  • What does use tokens, and only when you start it: modes and add-ons (a short note with your next message), time budget notes, the overseer, Fresh start and branching a session.

FAQ

Is this the real Claude Code?

Yes. Every tile runs the claude command you installed, with your login, settings, skills and MCP servers. Nothing is reimplemented.

Does it work with other agents, like Codex?

No. It's made for Claude Code only. Terminal tiles can run anything, but only Claude Code sessions get status, modes and the rest.

Does it cost anything?

The app is free and MIT licensed. Claude Code usage comes from your own plan, as always.

Why does my computer warn me when I open it?

The builds aren't signed by Apple or Microsoft yet, which costs money every year. The install steps show the one-time way past the warning. You can also build it yourself from the source.

A tile says Needs you, but nothing is asked.

Claude Code is showing a menu or tip at the bottom of that terminal. Answer it or press Esc.

It says "claude was not found".

The app starts claude through your login shell (PowerShell on Windows). Make sure claude --version works there, then press Resume on the tile.

The Mac says the app is damaged.

Run the xattr -cr command from the install steps.

Is there a Linux build?

Not yet. Mac and Windows only for now.

Uninstall

  • Mac: delete the app from Applications, and optionally ~/Library/Application Support/{{name}}.
  • Windows: uninstall it from Settings, Apps, and optionally delete %APPDATA%\{{name}}.

Your Claude Code sessions and history are untouched; they live in Claude Code's own folder.
