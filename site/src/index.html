The real claude, in real terminals.

Each tile runs the Claude Code you already use, with your own login, settings, skills and slash commands.

Answer from one list.

The overview puts every session that needs you first, across all your workspaces. Press 1, 2 or 3 to answer a permission menu without opening the tile.

One key for everything.

⌘K reaches every session, workspace, mode and action. Menus, shortcuts and the palette come from one list, so they always match.

Modes with real guards.

Put a session in Plan, Build, Review, Careful and more. Review and Plan really block file edits; Careful blocks risky commands like push and deploy.

No extra tokens.

Hooks reply with nothing unless you've asked for something. A mode is sent once, not with every message.

No telemetry.

No accounts and no server. The only thing it fetches is the update check from GitHub.

Your settings stay yours.

Sessions are ordinary claude processes, and your global Claude Code settings are never touched.

SmartScreen may not recognise the installer yet: click More info, then Run anyway. Claude Code must work as claude in PowerShell.

Questions

Is it really Claude Code?

Yes. Every tile is the real claude command in a real terminal. The app reads Claude Code's hooks to know what each session is doing and reimplements nothing.

Does it cost tokens?

Not on its own. A mode or add-on is sent once when it starts (and again after a compaction), a time budget adds a few one-line notes, and the overseer only uses tokens when you ask it something.

Why does my computer warn me about it?

The builds aren't signed or notarised yet. The first-launch steps above get you past the warning once.

I work on one project. Is it for me?

Yes. With one workspace you never see workspaces at all, just your sessions as tiles.

How does it update?

On Windows, updates download quietly and install when you choose Restart to update. On Mac the app tells you when a new version is out.

Is it made by Anthropic?

No. It's an independent open-source project, not affiliated with Anthropic.
