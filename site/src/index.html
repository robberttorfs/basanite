{{name}} is a command center for all your Claude Code sessions. See everything at a glance, let an overseer agent keep watch, and swap repetitive instructions for modes and one-click buttons, like a handover that clears a session to save tokens.

Tiles

Each session is a tile running the real claude command. A tile that needs you grows and turns amber. The one you're typing in doesn't move.

Overview

Every session in one list, the ones waiting on you at the top. Press 1, 2 or 3 to answer a permission menu from there.

Usage

Your 5-hour and weekly limits in the top bar. Cost per session and the last 14 days in the panel. Costs are estimates at API prices.

Workspaces

Group sessions by project and switch between them. Hidden sessions keep running, and their workspace shows a dot when one needs you.

Command palette

⌘K finds any session, workspace, mode or action, and shows its shortcut.

Changes

Every tile shows its git branch. Click it to read the diff, new files included. You get a note when two sessions edit the same file.

Modes

Plan, Build, Review, Test first, Debug, Until done, or your own. Review and Plan block file edits. Careful blocks push and deploy. A mode is sent once, not with every message.

History

Search a folder's past conversations and resume one in a tile.

Branch

Fork a session into a second tile, or start one on its own worktree.

Fresh start

Writes a handover, clears the context and carries on.

Time budgets

Give a session 30 minutes and it plans to fit.

Overseer

A small Claude in a side panel that can see all your sessions.

Terminal tiles

A plain shell. Run claude in it and it becomes a full session.

Questions

Is it really Claude Code?

Yes. Every tile is the real claude command in a real terminal, with your own login, settings, skills and slash commands. The app reads Claude Code's hooks to know what each session is doing.

Does it cost tokens?

Not on its own. A mode is sent once when it starts, and again after a compaction. Only extras you start yourself, like the overseer, use tokens.

Why does my computer warn me about it?

The builds aren't signed or notarised yet. The first-launch steps above get you past the warning once.

I work on one project. Is it for me?

Yes. With one workspace you never see workspaces at all, just your sessions as tiles. It works on any folder, git or not.

How does it update?

On Windows, updates download quietly and install when you choose Restart to update. On Mac the app tells you when a new version is out.

Is it made by Anthropic?

No. It's an independent open-source project, not affiliated with Anthropic.
