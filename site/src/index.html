It's the claude you already run.

Same login, settings, skills and slash commands. {{name}} gives each session a tile, listens to Claude Code's hooks to know what it's doing, and points at the one that's waiting.

Everything, sorted by who's waiting.

The overview is one list of every session in every workspace, needs-you first. The side pane shows the end of the conversation, and a number key answers a permission menu right from there.

Snooze the one that keeps asking. Done stays green until you've looked at it.

Plan mode that can't edit. Really.

Pick how a session works: Notes, Plan, Build, Review, Debug, Until done, or one you write. Add-ons like Verify at end stack on top. The mode goes to Claude once, not with every message, and shows its token cost as dots.

In Plan and Review, a hook blocks file edits. Careful blocks pushes, deploys and other risky commands. It stops the tool call itself, so it doesn't depend on Claude remembering the rules.

Type, don't hunt.

⌘K on Mac, Ctrl+Shift+K on Windows. Sessions, workspaces, modes, recent folders and every action. Each row shows its own shortcut, so after a week you won't need the palette much.

Menus, shortcuts and the palette all come from one list, so they always agree. This page has a small one too:

See the limit before you hit it.

Your plan's 5-hour and weekly limits sit in the top bar, with when they reset. Open them for what each session has used, and the last 14 days by day and by project.

It's all read from files Claude Code already writes. No API calls, and the costs are marked as estimates.

A small Claude in a side panel that can see every session. Ask "anything waiting on me?" It types into a session only when you tell it to.

Your tokens stay yours.

Watching is free. A few things do cost tokens, and you start each of them yourself.

  • No account, no telemetry, no server. The only request it makes on its own is the update check to GitHub.
  • Your settings stay put. Each session gets its hooks from its own settings file; your global Claude Code settings aren't touched.
  • Local only. It talks to sessions over 127.0.0.1 with a new random key every launch.

Download

The builds aren't signed by Apple or Microsoft yet, so the first launch takes one extra step. It's right under each download.

●Mac.dmg
Apple silicon Intel
  1. Open the .dmg and drag {{name}} into Applications.
  2. In Terminal, run this once:
    xattr -cr "/Applications/{{name}}.app"
    Or right-click the app, choose Open, then Open again.
  3. Open it and allow notifications.

  2. If SmartScreen doesn't recognise it, click More info, then Run anyway.
  3. Check that claude works in PowerShell.

Fair questions.

Is it really Claude Code in there?

Yes. Every tile runs the claude you installed, with your login, settings, skills and MCP servers. Nothing is reimplemented.

Does it cost anything?

The app is free and MIT licensed. Claude Code usage comes out of your own plan, same as in a terminal.

Why does my computer warn me about it?

The builds aren't signed yet; signing costs money every year. The install steps show the one-time way past the warning, or you can build it from source.

Does it work with Codex or other agents?

No, it's made for Claude Code. Terminal tiles run anything, but only Claude Code sessions get status, modes and the rest.

Linux?

Not yet. Mac and Windows for now.
